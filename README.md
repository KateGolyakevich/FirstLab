# Стоматологическая клиника

Лабораторная работа по программированию на C++.

## Описание

Программа моделирует работу стоматологической клиники.

В программе используются два класса:

- `Service` — стоматологическая услуга;
- `Patient` — пациент.

Для услуги хранится:
- название;
- врач;
- стоимость;
- продолжительность.

Для пациента хранится:
- имя;
- выполненные процедуры;
- количество выполненных процедур.

Количество процедур автоматически увеличивается при добавлении новой услуги пациенту.
